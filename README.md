# KaboofCasino

Paper 26.3 plugin for the Kaboof SMP: a rebuild of the Minecraft mod **MineVegas Casino** by byMehd for unmodified
clients, with a required server resource pack built from the mod's assets.

**MineVegas Casino:** https://www.curseforge.com/minecraft/mc-mods/minevegas-casino (MIT licence with attribution
condition; the mod's licence text is `LICENSE-MineVegas.txt` in this repository and in the plugin jar, and ships in the
resource pack under `credits/LICENSE.txt`).

Step 1 contains the foundation (pack build and delivery, machine framework, bet engine, GUI framework, storage,
commands) and the slot machine. Build, architecture and next steps: `docs/IMPLEMENTATION.md`.
